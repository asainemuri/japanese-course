动词的形式变化叫作活用（動詞の活用・どうしのかつよう）。

为什么「書く」可以变成「書かない」「書きます」「書けば」「書こう」「書かれる」「書かせる」？

一、活用的基本概念

1. 词形变化与接续

先看动词「書く（かく）」，意思是写。

書く（写）

否定

礼貌

条件

仔细观察三个变化：

  • 書かない

  • 書きます

  • 書けば

词干「書」没有改变，发生变化的是后面的假名。而「か」「き」「く」「け」「こ」恰好是五十音图中カ行的五个假名。现代日语的五段动词，其活用恰恰体现为词尾在五个元音段之间交替。

a, i, u, e, o\mathrm{a,\ i,\ u,\ e,\ o}

2. 六大活用形

传统学校语法将活用形分成六类。

活用形

五段「書く」

一段「食べる」

未然形

書か／書こ

食べ

连用形

書き

食べ

终止形

書く

食べる

连体形

書く

食べる

假定形

書け

食べれ

命令形

食べろ／食べよ

这一张表是我们整个日语语法学习体系的基础。这里有两点需要特别注意。第一，六大活用形是动词适应不同语法环境所采用的词形。五段动词的许多变化可以通过词尾的元音交替推导。然而「て形」「た形」涉及另一套音韵变化机制，我们稍后讨论。

六形活用与古典九形的对应关系

学校语法把现代活用分为六个形（未然・連用・終止・連体・仮定・命令），古典语法则分九个（未然・連用・終止・連体・已然・命令・仮定・体言接续等）。多出来的三个，正是理解 N1 文语构式的钥匙。

古典形

现代对应

现代残留

已然形（〜え）

并入现代仮定形

「〜ば」「〜ども」「〜ど」的接续基础

命令形（〜よ／〜ろ）

保留

「言え」「〜とはいえ」的「いえ」

連体形（〜る／〜き）

与終止形合流

「〜がたい」「〜べき」「〜ごとし」的连体接续

因此，N1 里的「〜ざるを得ない」（未然形＋ざる）、「〜んがため」（未然形＋ん＋が＋ため）、「〜べく」（べし的连用形）、「〜まい」（古典否定推量）都不是孤立公式，而是古典九形在现代句法中的系统性投影。记住这条映射，文语构式就从「一个个背」变成「按活用表推导」。

二、动词类型与活用

1. 五段动词

以「書く」为例：

カ行五段活用

我们从五个元音段分别分析。「書く」变为未然形「書か」后接「ない」，得到「書かない」；变为连用形「書き」后接「ます」，得到「書きます」。

ア段：未然形，常用于否定、被动、使役

書く → 書か＋ない → 書かない

「ない」接在动词的未然形后面，表示否定。

  • 読む → 読まない

  • 話す → 話さない

  • 行く → 行かない

  • 帰る → 帰らない

再看被动：

書か＋れる → 書かれる

使役：

書か＋せる → 書かせる

这三个形式都采用五段动词的未然形「書か」。“未然形”是活用形的名称。接「ない」构成否定，接「れる」构成被动，接「せる」构成使役；具体意义由后接成分确定。

イ段：连用形

書く → 書き＋ます → 書きます

「ます」需要接在连用形后面。

書き＋たい → 書きたい

表示想写。

書き＋ながら → 書きながら

表示一边写，一边做另一件事。

書き＋方 → 書き方

表示写的方法。

「書き」不仅能连接各种语法成分，还能作为构词基础，参与形成名词或复合词。

書き直す（重新写）

「書き」是「書く」的连用形，「直す」表示重新处理、修正。这也是复合动词的一种构词方式。

ウ段：终止形与连体形

書く。

句子到这里结束，「書く」是终止形。

書く人

修饰后面的名词「人」，此时是连体形。

现代五段动词的终止形与连体形在形态上相同，但在传统语法分析中依然被区分。为什么要区分两个看起来完全相同的形式？因为在古典日语中，它们原本不一定相同。例如古典日语的上一段、下一段以及部分其他活用类型，终止形与连体形存在形态差异。现代日语经历了形态合流，很多区别消失了，但语法功能仍然不同。

这就是为什么日语语法书里会出现两个名称，却经常给出同一个词形。

エ段：假定形与命令形

書け＋ば → 書けば

表示如果写的话。

書け！

表示写！是命令形。

所以「書け」可以承担两种不同的功能：

  • 后接「ば」形成条件表达。

  • 单独使用时构成命令形。

两者形式相同，语法功能不同。「書ける」是「書く」的可能形，表示「能写」。它与假定形、命令形都涉及エ段，但各自的语法功能不同。

オ段：意志形

書こ＋う → 書こう

表示「写吧」「我要写」。

  • 読む → 読もう

  • 行く → 行こう

  • 話す → 話そう

这里的「う」是现代日语意志形的构成成分。从历史上说，五段动词源于古典日语的四段活用，现代意志形还经历了音变，例如「書かう」演变为「書こう」。现代五段活用的五个元音段，是在历史演变中逐渐形成的。

为什么五段动词的否定是「書かない」而不是「書くない」

五段动词接否定时要先变未然形——把词尾从ウ段挪到ア段：書く→書か、読む→読ま、話す→話さ。这个「挪一段」不是随意的规定，而是古典否定助动词「ず」的接续要求留下的活化石。

古典日语中，「ず」只能接在未然形之后（「書かず」「読まず」）。未然形之所以叫「未然」，正因为它表示「事态尚未成立」——与否定、推量、意志这些非现实范畴天然契合。现代否定「ない」接替了「ず」的位置，也就继承了它的接续条件：必须先进入未然形，才能接否定。于是「書くない」不成立，因为「書く」是终止形，属于「已然／现实」一侧。

一条规律串起四类形式：凡表非现实的语法范畴，五段动词都用ア段（未然形）接续——
① 否定：書か＋ない
② 被动：書か＋れる
③ 使役：書か＋せる
④ 意志・推量：書こ＋う（オ段，属未然形的另一支）
反之，凡表现实进程的范畴，都用イ段（连用形）：書き＋ます／書き＋たい／書き＋ながら。记住这条「未然—现实」的分水岭，活用表就不再是一堆孤立规则。

还有一处常被忽略的细节：ア段音的选择。五段动词词尾若本身是「う」（如「買う」「言う」），未然形是「買わ」「言わ」而非「買あ」——历史上「あ」行音在词中转为「わ」行，与上一课提到的ハ行转呼同源。而「ある」的否定是「ない」而非「あらない」，则是另一条更古老的「补充形」规则：「ある」的否定自古就借用形容词「なし」，这是日语中最著名的形态补充（suppletion）现象。

对照

書かない／書かれる／書かせる／書こう（未然形：否定・被动・使役・意志）
書きません／書きたい／書きながら（连用形：礼貌・愿望・同时）

2. 一段动词

观察：

食べる → 食べない

而不是

食べる → 食ばない

因为「食べる」是一段动词。一段动词的核心机制是：去掉词尾「る」，保留稳定的词干，然后连接不同的语法成分。

「食べる」的活用结构

否定食べ＋ない食べない
礼貌食べ＋ます食べます
条件食べれ＋ば食べれば
意志食べ＋よう食べよう
命令食べ＋ろ食べろ

「一段」这个名称与「五段」相对应：一段动词的词干末尾元音基本保持在同一个元音段，不像五段动词那样在五个元音段之间交替。现代一段动词还可以分为：上一段活用：词干末尾元音为 /i/。

  • 見る → 見ない

  • 起きる → 起きない

  • 借りる → 借りない

下一段活用：词干末尾元音为 /e/。

  • 食べる → 食べない

  • 寝る → 寝ない

  • 教える → 教えない

这两个名称来自五十音图传统排列中，イ段位于ウ段上方，エ段位于ウ段下方。

「帰る」的五段活用

这是日语初学者容易遇到的陷阱。

食べる → 食べない

帰る → 帰らない

同样是「る」结尾，而且「帰る」前面的假名也是エ段，但两者的活用类别不同。

常见五段动词包括：

  • 帰る（かえる）

  • 走る（はしる）

  • 入る（はいる）

  • 知る（しる）

  • 切る（きる）

  • 要る（いる）

「イ段／エ段＋る」可以作为识别一段动词的线索，还需结合具体活用来确认。甚至还有同音但活用不同的例子：

着る（きる）：穿衣，一段。

切る（きる）：切割，五段。

比较：

  • 服を着ない。

  • 紙を切らない。

只有结合词义和词汇本身的活用类别，才能正确变形。

三、て形与た形的音便

五段动词连接「て」「た」时，连用形的末尾还会发生音变。

書く → 書いて

「書き」连接「て」时，形成「書いて」。

読む → 読んで

「読み」连接「て」时，形成「読んで」。这类语音变化称为音便。音便（おんびん）：为了适应发音，词语在历史发展中产生的语音变化。现代五段动词的「て形」和「た形」，主要受这一机制影响。

音便的语音动因：为什么偏偏是イ・促音・撥音

音便不是任意的「习惯」，而是发音器官为省力而进行的同化。古典日语中，连用形「書き」「立ち」「読み」接续「て／た」时，中间夹着元音，发音费力，于是发生三种规律性的音变：

音便

触发条件

例

语音机制

イ音便

カ行・ガ行（く・ぐ）

書きて→書いて／嗅ぎて→嗅いで

k・g 在t 前脱落，残留的i 成为音节核。

促音便

タ行・ラ行・ワ行（つ・る・う）

立ちて→立って／取りて→取って

舌尖音同化为t，急闭气流形成促音っ。

撥音便

ナ行・バ行・マ行（ぬ・ぶ・む）

死にて→死んで／読びて→読んで

鼻音n・m 保留为ん，后接浊化で。

「行く」为什么是特例？按规则，カ行行く应走イ音便，说成「行いて」；但现代标准语固定为「行って」。通说认为，上代「行く」的连用形「行き」与表示「去」的另一个词干发生混同，加之「行く」与促音便的「帰る・入る」同属移动动词，在类推作用下被拉入促音便阵营。这个例外必须与「書いて」类规则形式分开记：误用行いて／正例行って。

音便的历史层次还体现在形容词上：「高く＋あり」→「高かり」是カリ活用的由来，「高く＋ございます」→「高うございます」是ウ音便（上方方言色彩），而现代口语的「高かった」又是在カリ活用基础上加促音便的结果。三种音便叠在同一条词尾上，正是日语「一层压一层」的活化石。

从音变的角度理解更容易记住。「読む」原本以「読み」这个连用形为基础，后接「て」或「た」，后来发生拨音便：読み＋て ⟶ 読んで\text{読み＋て}\ \longrightarrow\ \text{読んで}

2. 「行く」的促音便

行く → 行って → 行った

「行く」以「く」结尾，て形和た形却采用促音便，分别是「行って」「行った」。

3. 一段动词与不规则动词的て形

一段动词十分简单：

  • 食べる → 食べて → 食べた

  • 見る → 見て → 見た

  • 起きる → 起きて → 起きた

特殊活用：

  • する → して → した

  • 来る → 来て（きて）→ 来た（きた）

「て形」和「た形」的词干变化模式基本一致。

  • 書いて／書いた

  • 読んで／読んだ

  • 話して／話した

  • 食べて／食べた

掌握其中一种，另一种就很容易推导。

「する」与「なる」：日语自他对应的总枢纽

日语动词的自他对应看似杂乱（「開く／開ける」「決まる／決める」「増える／増やす」），但只要抓住「なる」（自）与「する」（他）这一对总枢纽，就能把绝大多数对应关系串起来。

只有自动词，他义用别的词（「置く」）。

自他选择的背后，是说话人把镜头对准哪里：用自动词时，句子聚焦变化的自然发生（「ドアが開いた」——谁开的不是重点）；用他动词时，聚焦某人的作用（「ドアを開けた」——有人开了）。这条区分为后面学习被动、使役、责任归属打下基础：日语新闻常用自动词来淡化施事责任——

对比

担当者が書類を紛失した。（负责人弄丢了文件——责任明确。）
書類が紛失した。（文件丢失了——施事隐去，责任被淡化。）

学习建议：不要把自他动词当成一个个孤立的词条背，而要成对记，并在记的时候问一句——「这句话的镜头对准变化本身，还是对准人的作用？」答案决定用自动词还是他动词。这条思路一旦建立，后面学「〜てある」「〜ておく」「〜ている」的差别，以及被动句的视点，都会顺理成章。

しろ／せよ

「せよ」是古典命令形，保留在书面语。

「来る」的不规则来自词干本身的音变：古典形是「来（く）」，各活用都以く为核心，但在连用、未然等位置，「く」受前后元音影响转为こ／き，形成「こない・きます・くる・くれ・こい」这一串看似不相关的形态。若用假名读音去记（こ・き・くる・くる・くれ・こい），就能看出它们其实是同一个词根的不同音形。

「する」则来自古典サ行变格活用的「す」，本就是「做」的意思。它之所以有三个未然形，是因为要分别接续不同的古典助动词：「し」接「ない」「よう」（しない・しよう）、「せ」接「ず」「ぬ」（せず・せぬ）、「さ」接「れる」「せる」（される・させる）。现代日语把它们都保留了下来，于是看起来像「三套未然形」。

与 N1 句型的连接：正因为「する」有「せ」这一未然形，才有「〜せざるを得ない」「〜せずにはいられない」「〜せざる」等文语构式；也正因为「来る」的未然形是「こ」，才有「〜こざるを得ない」（罕见）与「来（こ）ない」。变格活用不是「例外」，而是古典活用系统的活化石——记住这一点，N1 的文言构式就有了落脚点。

连用形的四种去向：ます・て・たい・ながら

五段动词的连用形（イ段）是活用表里最忙的一格。它同时供应四类后续成分，而每一类对它的要求都略有不同——理清这一点，就不会再把「書き」与「書い」混为一谈。

接续对象

形式

说明

礼貌助动词「ます」

書きます

保持原形「書き」，不发生音便。

接续助词「て／た」

書いて／書いた

发生音便，连用形末尾改变。

愿望助动词「たい」

書きたい

同「ます」，不加音便。

接续助词「ながら」

書きながら

同上，表同时进行。

复合动词前项

書き直す

不带音便，构成新的复合词。

规律很清楚：音便只发生在接「て」「た」时，其余场合连用形保持原样。许多学习者写出「書いたい」这样的错误，正是因为把「た」的音便规则错用到了「たい」上。记住：「たい」是助动词，不是助动词「た」——两者外形相近，接续条件毫不相干。

一段动词的对照：「食べる」的连用形只有「食べ」一种，接「ます」「て」「たい」「ながら」全部同形（食べます・食べて・食べたい・食べながら），因为一段动词没有音便问题。真正的难点集中在五段动词，而五段的音便又只服务于「て／た」这一对。把「音便」和「连用形」分开理解，活用表就只剩一条主线。

还有一处历史细节：「ます」本身来自古典敬语助动词「ます」（「参らする」的缩约），它从一开始就要求接在连用形之后；而「て」来自古典接续助词「て」，同样要求连用形。二者接续相同、命运不同——前者稳定不变，后者引发了整场音便革命。这条对比，正是「同一接续位置可以有截然不同的历史走向」的绝佳例证。

四、活用的组合与来源

1. 复合形式的构成

以「書く」为例：

从「書く」衍生出的主要语法形式

否定書かない不写
被动書かれる被写
使役書かせる让／使写
可能書ける能写
愿望書きたい想写
意志書こう写吧／打算写
条件書けば如果写
过去書いた写了

这些形式还可以继续活用。

書かせる → 書かせない

不让写。

書かせる → 書かせられる

被迫写、被要求写（使役被动）。

書ける → 書けない

不能写。

日语动词形式可以逐层组合，语态、情态、否定和时态等各有接续顺序。例如「書かせられなかった」可以分析为：書かせられる→書かせられない→書かせられなかった\text{書かせられる}\rightarrow\text{書かせられない}\rightarrow\text{書かせられなかった}

表示过去没有被迫写，具体含义还要结合上下文。

一个与 N1 密切相关的问题

为什么：

食べられる

既可以表示「能吃」，也可以表示「被吃」？

因为一段动词的可能形式与被动形式在标准语中存在形态重合。

この魚は食べられる。

可能表示这条鱼可以食用，也可能在特定语境中表示这条鱼被吃。

日常口语里存在「食べれる」这样的「ら抜き言葉」，使可能意义与被动意义在形式上更容易区分，但在正式考试和标准书面表达中，仍应熟悉「食べられる」的规范形式。之后我们会专门学习可能、被动、使役和自发的意义差异。

2. 古典活用的现代残留

如果只记住现代日语的「ない」「ます」「た」，那么遇到以下形式很容易困惑：

  • 書かず

  • 書かざるを得ない

  • 書くまい

  • 書かんがため

它们为什么不按照现代常见表达方式变化？因为其中保留了古典日语的助动词和活用形式。「ずにはおかない」里的「ず」也接未然形，与「書かず」的构造相同。

「〜ず」：古典否定助动词的遗留

書か＋ず → 書かず

表示不写。

何も言わずに帰った。

什么也没说就回去了。

「ず」与现代否定助动词「ない」具有相近的否定功能，但它属于古典日语助动词体系的遗留形式。注意「する」：

何もせずに帰った。

「する」的这个古典否定形式是「せず」。

「〜ざるを得ない」：不得不……

書かざるを得ない。

表示不得不写。

拆解：書か+ざる+を得ない\text{書か}+\text{ざる}+\text{を得ない}

「ざる」是古典否定助动词「ず」的连体形（相关形式）；「を得ない」表示无法获得不这样做的余地，整体形成「不得不」的表达。

計画を変更せざるを得ない。

不得不修改计划。

特别注意

する → せざるを得ない

「〜まい」：否定意志或否定推量

二度と行くまい。

再也不去了。

「まい」保留了古典否定推量、否定意志助动词的性质。现代日语里通常有两类用法：

  • 否定意志：绝不……

  • 否定推量：恐怕不会……

彼はもう戻るまい。

可以理解为「他恐怕不会再回来了」。和「戻らないだろう」相比，「戻るまい」显得更书面、更有文学性。

「〜んがため」：为了……

合格せんがため、必死に勉強した。

为了通过考试，拼命学习。

这里的「ん」与古典助动词「む」有关。它来自古典日语表示意志、推量的「む」的音变形式。「せん」相当于古典式的「しよう」，再加「がため」表示目的。结构：

する→せん+がため\text{する}\rightarrow\text{せん}+\text{がため}

「合格せんがため」便是「为了要合格」。这个句型在现代日语日常对话中很少使用，但非常适合出现在 N1 书面语、文学或正式表达中。许多高级句型都保留着古典日语的词形，并把它们用在现代语法结构中。这也是我们为什么要从活用体系讲起。

「べし」的现代残影：べき・べく・べからず

「べし」是古典日语的当为助动词，接在动词终止形之后，表示「理应如此」。它按形容词式活用，衍生出现代日语里三个面目不同、却同出一源的形式。

形式

来自「べし」的哪一形

现代用法与语体

〜べきだ

連体形べき＋断定

「应当……」，书面论说与演讲常用，带客观规范色彩。

〜べく

連用形べく

「为了……」，文言色彩浓，多用于正式文书与社论。

〜べからず

未然形べから＋ず

「不得……」，仅存于告示、标语与格言。

三者的语体落差极大。「〜べきだ」已完全现代化，可自由用于日常议论；「〜べく」则几乎只在书面语中出现，且后项多为意志性动作（「留学すべく準備する」）；「〜べからず」则彻底成语化，只剩下「入るべからず」「油断すべからず」这类固定告示。

一个必须避开的误用：「〜べき」的否定不是「〜べくない」，而是「〜べきではない」或文言式的「〜べからず」。误用行くべくない。
另外，「する」接「べし」时古典形式是「すべし」，现代固定说法「〜すべきだ」正由此而来——这也解释了为什么「するべき」与「すべき」并存，而后者更受规范语法推崇。

把这三个形式与第 24 课的「ず・ぬ・ざる・まい」放在一起看，会发现一条清晰的谱系：古典助动词并未消亡，而是退入书面语的特定语域，以固定构式的形式继续存活。N1 阅读中遇到它们，判断语体比翻译词义更重要——它们几乎总是作者在拉开距离、强化权威的信号。

可能形与「ら抜き言葉」：语法的现在进行时

日语的可能表达正在经历一场尚未结束的形态变化：一段动词的可能形，从古典的「食べられる」正在向「食べれる」过渡。这种现象被称为ら抜き言葉（去掉「ら」的说法），是观察「活用的历史正在发生」的活标本。

动词类型

规范可能形

ら抜き形

现状

一段

食べられる

食べれる

口语广泛使用，正式场合仍不推荐。

五段

書ける

—

无此现象，五段可能形本就短。

来れる

同上，口语常见。

する

×される（非可能）

「する」的可能形是「できる」，形态补充。

「ら」为什么会掉？因为一段动词的可能形「食べられる」与被动形完全同形，造成大量歧义——「食べられる」既可解为「能吃」也可解为「被吃」。说话人为了区分可能与被动，倾向把可能形缩短为「食べれる」，让被动形独占「られる」。这不是「错误」，而是语言为消除歧义而进行的自我调整，与历史上「行く」从「行いて」转向「行って」属于同一性质。

使用建议（N1 应试与写作）：① 书面语、正式文书、考试作文一律用规范形（「食べられる」）；② 会话与小说对白可用「食べれる」以贴近口语；③ 注意「見れる」「来れる」在年轻人中已近乎标准，但「寝れる」仍被认为较随便。判断标准不是「对不对」，而是「这个场合容许不容许口语化」。

顺带一提，可能形的对象助词也有变化：规范语法要求「日本語が話せる」（用「が」），但口语里「日本語を話せる」也很常见。这一现象与本课所讲的自他对立同源——可能句把动作变成状态，对象随之从「宾语」转为「状态的主体」，助词也就跟着从「を」滑向「が」。

遇到动词时，先判断它属于哪一种：

否定、礼貌、条件、意志、语态、过去……

一段和五段的区别是第一层。未然形、连用形、假定形等是第二层。音便与古典遗留形式是第三层。据此可以把长形式逐层拆开：先认出动词和活用形，再确认否定、使役、被动、过去等后接成分的作用。

六、课后练习

除了选择正确变形，还要区分现代活用与古典遗留形式。

1. 「走る」的否定形是哪一个？

查看答案与解析

正确答案　B　走らない

「走る」虽然以イ段假名＋る结尾，却是五段动词，因此未然形为「走ら」。

2. 「泳ぐ」的过去形是哪一个？

查看答案与解析

正确答案　C　泳いだ

ガ行五段动词的て形、た形发生イ音便并伴随浊音：「泳いで／泳いだ」。

3. 「書けば」中的「書け」属于什么活用形？

查看答案与解析

正确答案　C　假定形

「書けば」是五段动词的假定形「書け」连接「ば」形成的条件表达。

4. 以下哪一组全都是一段动词？

查看答案与解析

正确答案　A　食べる・見る・起きる

「食べる」「見る」「起きる」都是一段动词；「帰る」「走る」「知る」「入る」为五段动词。

5. 「研究する」变成「不得不研究」，正确的是？

查看答案与解析

正确答案　C　研究せざるを得ない

サ变动词「する」在古典否定形式「ず／ざる」之前使用「せ」：「研究せざるを得ない」。

6. 「食べられる」在现代标准日语中可能表达什么？

查看答案与解析

正确答案　C　可能或被动等，依语境判断

一段动词的可能与被动形式存在重合；此外「られる」还与尊敬等用法有关。
